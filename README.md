# ship-it-skynet

> A reference matrix comparing agentic AI coding CLIs. Continuous deployment, continuous dread.

**Last updated:** 2026-08-10 &nbsp;·&nbsp; **Matrix last verified:** 2026-08-10 (all three tier-1 columns)

This is not another "best AI tool 2026" listicle. It's a Rosetta stone: row-per-feature, column-per-tool lookup for developers who already use one of these CLIs and want to know what the other side has.

## Principles

- **Primary sources only.** Every non-trivial claim links to official docs, a changelog, or a commit. Nothing from Twitter.
- **Dated.** Each column has a "last verified" date. Run `/refresh` to re-verify.
- **No vibes benchmarks.** We don't rank "which writes better React." That's a blog post, not a reference.
- **Opinions live in prose, not cells.** The intro can say "Claude Code's hooks are the only implementation I'd bet a CI pipeline on." Cells just say yes / no / partial.
- **Maintainable by one person.** If updating the matrix takes more than 30 minutes, the format is wrong.

## Scope

**Tier 1** (this matrix): Claude Code, Codex CLI, Antigravity CLI (successor to Gemini CLI, whose consumer tiers sunset 2026-06-18).

**Tier 2** (considered for deep-dives, not the main matrix): Aider, Cline, Cursor CLI, Windsurf / Codeium, Continue.dev.

**Out of scope:** IDE plugins without terminal UX (Copilot), web UIs (ChatGPT, claude.ai), model-hosting services. This is about terminal-first agents.

See [`docs/glossary.md`](docs/glossary.md) for vendor-terminology mappings — half the confusion between these tools is that "agent" means five different things.

> All three tier-1 columns were re-verified against primary vendor docs on 2026-08-10. Two asymmetries worth flagging: Codex CLI's hook surface keeps expanding — a lifecycle catalog that is enabled by default and still growing (`SessionEnd` joined it since the last refresh), `updatedInput` tool-input rewriting on `PreToolUse`, and interception of the unified-exec streaming shell and other local function tools, leaving hosted tools like `WebSearch` as the only documented hole — but the docs still call hooks "a useful guardrail, not a complete enforcement boundary," noting that some specialized tool paths can opt out, so it still isn't a CI-pipeline gate (see [hooks deep-dive](docs/hooks.md)); and Claude Code remains the only tier-1 CLI with a full **Agent Teams** layer (experimental, flag-gated behind `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`) where teammates run as independent sessions, share a task list, and message each other directly — Codex CLI subagents are strictly hierarchical (parent → children, no peer messaging), and Antigravity documents inter-agent messaging by conversation ID plus an Ultra-plan-gated `/teamwork-preview` framework, but no shared task list (its predecessor Gemini CLI was a verified ❌) — which is why Agent Teams earns its own matrix row. New on 2026-08-10: a **Cross-session messaging** row for the adjacent-but-different capability. Claude Code sessions you started yourself can now discover and message each other by name (`ListAgents` + `SendMessage`, surfaced as `/list-agents` / `/peers`), same-machine delivery riding a per-session Unix inbox socket rather than Anthropic servers; Antigravity documents a `send_message` tool that routes to "peer agents whose ID is known" but addresses them by agent conversation ID inside one agent tree, with no documented way to discover independent CLI sessions; Codex documents no session-to-session channel at all.
>
> The 2026-06-10 column swap: **Gemini CLI → Antigravity CLI** (`agy` — v1.1.11 as of the 2026-08-07 release). At swap time only fourteen of nineteen rows were verifiable, all from the official repo's README and CHANGELOG; the other five — plan mode, agent teams, hooks, web search, and checkpoints/rewind — waited on real documentation, because Gemini inheritance (`~/.gemini/` config paths, Gemini models underneath) isn't evidence. On 2026-07-11 the documentation landed — antigravity.google now publishes an `llms.txt` index and serves each doc page's raw markdown — and all five cells resolved: plan mode ✅ (one of three execution modes, with `Shift+Tab` cycling and a `--mode=plan` flag), hooks ✅ (a `hooks.json` lifecycle with hard-blocking `PreToolUse`), web search ✅ (built-in `search_web` and `read_url_content` tools), checkpoints/rewind ✅ (`/rewind` plus a conversation-level `/fork`), and agent teams 🟡 (documented peer messaging and an Ultra-plan-gated `/teamwork-preview`, but no shared task list). The Codex CLI column moved too, without a single symbol changing: OpenAI relocated the entire Codex docs tree from developers.openai.com to learn.chatgpt.com (every old URL 301s there) — and then moved it back: by 2026-07-25 the canonical URL space (per the vendor's own `llms.txt`) is developers.openai.com/codex/ again, with learn.chatgpt.com serving byte-identical mirrors, so all Codex citations follow the canonical host once more. The 2026-08-10 refresh then moved three Antigravity citations off GitHub and onto canonical pages that did not exist at the last run — `cli/headless`, `cli/mcp`, and `cli/prompting` — closing the last places where this column cited a CHANGELOG for want of a doc page.
